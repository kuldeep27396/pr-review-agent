# GitHub PR Review Agent

Pure Python GitHub PR review agent for GitHub Apps.

This repo used to run on Node/Express. It now runs on Python with FastAPI, keeps the same webhook entrypoint, and adds a cleaner review pipeline inspired by public review agents such as:

- `qodo-ai/pr-agent`
- `coderabbitai/ai-pr-reviewer`
- `RedVentures/red-rover`
- `codedog-ai/codedog`
- `tusgino/llm-code-reviewer`

## What Changed

- Replaced the Node runtime with a Python service in `pr_review_agent/`
- Kept the GitHub App webhook flow: verify webhook, fetch PR files, analyze changes, post a review
- Added an LLM provider abstraction for `groq` and `openai`
- Added optional provider fallback and true GitHub review states
- Switched review inputs to be diff-first instead of sending only raw file content
- Added filtering inspired by the reference repos:
  - file include/exclude patterns
  - trivial-change skipping
  - added-line-only inline comments
  - capped inline comment count
- Added repo-level config support via `.pr_review_agent.toml`
- Added incremental reviews, duplicate-delivery protection, generated-file filtering, and review-comment replies
- Updated Docker, Railway, Render, Nixpacks, and GitHub Actions for Python

## Architecture

```text
GitHub Webhook
  -> FastAPI webhook handler
  -> GitHub App auth + PR file retrieval
  -> Diff-aware review pipeline
  -> OpenAI-compatible LLM provider (Groq/OpenAI)
  -> GitHub PR review summary + inline comments
```

## Runtime

- Python `3.11+`
- FastAPI for the webhook service
- `httpx` for GitHub and LLM API calls
- `PyJWT[crypto]` for GitHub App JWT signing

## Local Run

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
uvicorn pr_review_agent.main:app --host 0.0.0.0 --port 3000
```

Health check:

```bash
curl http://localhost:3000/health
```

## Docker

```bash
docker build -t pr-review-agent .
docker run --env-file .env -p 3000:3000 pr-review-agent
```

## Main Files

- `pr_review_agent/main.py`: FastAPI app and webhook orchestration
- `pr_review_agent/github.py`: GitHub App auth, PR file retrieval, review posting
- `pr_review_agent/llm.py`: OpenAI-compatible provider client
- `pr_review_agent/review.py`: diff parsing, prompting, issue filtering, summary generation
- `pr_review_agent/config.py`: env-driven settings

## Repo-Level Config

The reviewed repository can add `.pr_review_agent.toml` at its root:

```toml
[review]
exclude_patterns = ["docs/**", "vendor/**"]
max_comments_per_review = 10
review_simple_changes = false
enable_incremental_reviews = true
enable_test_plan = true
ignore_keywords = ["@agent ignore"]
summary_only_keywords = ["@agent summary-only"]
bot_aliases = ["@agent", "@pr-review-agent"]
```

## Reference Features Adopted

From the cloned public repos, the rewrite intentionally incorporates:

- Qodo/PR-Agent style diff-first review inputs and configurable behavior
- CodeRabbit/RedRover style split between review model and summary model
- RedRover style multi-provider support
- Codedog style explicit review data models and clean component separation
- LLM Code Reviewer style file exclusion patterns and lightweight configuration
